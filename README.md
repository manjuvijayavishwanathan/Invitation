# 🎉 Friends Reunion Invitation

A simple and attractive digital invitation website created for a Friends Reunion event.

## 📌 About the Project

The Friends Reunion Invitation is a static web page designed to invite friends to a reunion event. It presents the event details in a simple, attractive, and user-friendly format.

## 🎯 Objectives

- Create a digital invitation for a friends reunion.
- Present the event details clearly.
- Design an attractive and responsive invitation webpage.
- Provide an easy-to-share alternative to traditional invitations.


## 🛠️ Technologies Used

- HTML5
- CSS3
